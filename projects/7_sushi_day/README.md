## 一、项目定位

通过"Sushi 高品质专区"以**折扣菜 + Keeta 独家组合套餐**两大供给击穿高 AOV 用户转化瓶颈（202608 复盘核心卡点：高偏好商户无折扣菜）。商家拿"名额与流量"，不是单向让利。

**目标**：10 家高偏好商户，各拿 ≥6 个 40%off+ 折扣菜 + ≥1 个独家套餐；第一阶段首签 2 家（Renata Leite / Sabrina Fernandes）。

## 四、核心账（谈判用）

- **三层折扣结构**：顾客看到 50-70% off = 商家 40pp（商补率红线）+ 平台补贴 10-30pp（补至 R$29.9/49.9）
- **Premier 套餐**（4档：双人尝鲜 R$60 / 品质分享 R$96 / 豪华聚会 R$120 / 高端奢享 R$156）均为整 40%off，AOV 设计对齐高 AOV 人群基准 R$91.6
- **库存 20 份** = 商家让利封顶承诺（20×40%×客单），谈判时主动讲
- **资源**：首页楼层日均曝光 2w+ / 会场 5000+（算法分发，无坑位承诺，话术只给区间）；上线 9/11 起每周五 17:00-23:00

## 五、待决口径（⚠️ 持续追踪）

1. **Premier 套餐是否叠平台补贴**（对齐 Mia/Ron）——我的建议：不叠价格补贴，补贴集中折扣菜；Premier 增量用免运费/赠品形式（保价格锚点，预算同池）
2. 4.1 招商要求行未填（折扣菜≥6×40%off + 独家套餐≥1 + 商补40% 需搬入）
