### Q18：BI 看板取数有什么限制？
BI 看板取数读取的是 `bi.keetapp.com` 页面，依赖浏览器、网络和页面组件状态。

已知限制：

- 页面必须能在浏览器中正常打开并完成登录。
- 复杂自定义组件、XBR 页面或非标准表格组件可能只能截图，无法稳定抽取结构化数据。
- 看板取数适合读取页面展示内容，不保证能还原底层 SQL 或明细数据。
- 境外网络或沙箱浏览器异常时，需要先人工打开页面确认可访问。

### Q19：群 AI 助理能直接用吗？
当前主要适配个人 AI 助理和本地 Skill 执行环境。群 AI 助理是否可用取决于平台是否允许该 Skill 的 CLI、mtcli 和浏览器能力运行。

---

### Q20：还有哪些旧链路已删除？
以下旧链路不要再使用，也不要在回答里引导用户走这些方式：

- 直连 BI 个人数据集 HTTP 接口
- 直连 SQL 模板 HTTP 接口
- 非看板业务通过浏览器 Cookie/CDP 读取登录态

个人数据集和 SQL 模板的 `kdata` 对外命令保持不变：`kdata dataset ...` / `kdata template ...`。变化只在内部实现：它们现在调用 `mtcli kdata moshu ...`。

对应替代能力见 [查询与使用](faq-query.md)。
