## 🔄 取数方式（优先级）

```
优先级 1 ▶ DOM 文本提取（精度 100%）
  - 通过 CDP (localhost:9222) 向页面注入 JS
  - 扫描渲染完成的 <table>、交叉表（cross-table/pivot/AntV S2）、KPI 卡片
  - 直接读取 DOM 文本，无需截图/OCR
  - 输出：/tmp/files/dbr_data.json（data_source="dom"）

优先级 2 ▶ 截图兜底
  - DOM 有效值 < 5 时自动降级
  - 截图路径：/tmp/files/tab_bp.png / tab_ns.png / tab_op.png / tab_promo.png / tab_ux.png
  - 输出：/tmp/files/dbr_data.json（data_source="screenshot"）
```

> ⚠️ CSV 下载方案已暂停：BI 看板下载文件走文枢 DRM（cryptbox://），沙箱无客户端，无法取到文件。详见 `workspace/tasks/BACKLOG.md`。

取数命令：

`--date` 可选，默认取 BRT 昨天。

## 🩺 健康检查 & 常见问题

### BI SSO 失效
```bash
curl -s http://localhost:9222/json/list | python3 -c "
import json,sys
tabs=json.load(sys.stdin)
for t in tabs:
    if 'bi.keetapp' in t.get('url',''):
        print(t['url'])
"
```
- 输出包含 `login` → SSO 失效，DM 文乐「BI登录失效，请重新扫码」
- 输出包含 `dashboard` → 正常

### 数据取错日期
根因：`dbr_fetch.py` 早期版本硬编码日期。当前版本已修复，强制用 `--date` 参数或动态计算 BRT 昨天。

### 图片底部大片空白
根因：`dbr_template_v7.html` 含旧的 `.summary-box` 区块（已删除）。若再现：
```python
# PIL 裁剪实际内容区域
from PIL import Image
img = Image.open('/tmp/files/dbr_card.png')
# 从底部扫描非背景像素
```

### 机器人发群失败（70003）
确认机器人 `65a6eb395a` 在群 `70415285284` 中，联系管理员重新邀请。

### DOM 提取成功但数据为空
- 原因：页面尚未渲染完（数据还在加载）
- 解法：检查 `await asyncio.sleep(5)` 是否足够；或 SSO 失效导致空页面
