## Business Platform 看板每日更新 (Cron 18:30 CST / 07:30 BRT)

Cron 提醒触发，尝试执行 BP Dashboard 每日数据更新。

### 尝试过程

1. **检查现有脚本**: 发现多个 BP 相关脚本 (update_bp_dashboard.py, fetch_bp_data_today.py, gen_bp_dashboard_v2.py 等)
2. **CDP 直接查询**: 通过 websockets 连接浏览器 CDP，发现 `executeQueryAndGetCHNResult` 返回空数据（0 rows），图表容器未渲染
3. **Playwright 脚本取数**: 使用 `bi-query-dashboard-overseas` Skill 的 `fetch_with_playwright.py`
   - 成功复用现有 BI 页面 (dashboardId=300001446)
   - 通过拦截网络请求捕获数据 API
   - 发现 8 个 Tab，但脚本提前退出逻辑导致只捕获了部分数据
   - 修复了脚本的提前退出逻辑（timeout>300s 时不提前退出）
   - 最终仍只捕获到 "New Sign" Tab 的数据（7 行，日期 20260912）
   - 其他 Tab 的数据 API 响应结构不匹配，显示"没有数据或列信息"

### 取数结果

- **New Sign**: 7 行数据，日期 2026-09-12，包含 KA/SA/SMB(Long-Tail/Mid-Tier/Must-have/Top-Tier) 的订单量、AOV、GMV、CTR 等指标
- **其他 Tab**: 未成功捕获

### 问题分析

1. BI 看板在 headless/CDP 环境下图表不渲染，导致 DashboardController 直接查询返回空
2. Playwright 网络拦截方式只能捕获已触发的请求，部分 Tab 的 chart 懒加载未触发
3. 脚本对部分数据 API 响应解析失败（"没有数据或列信息"）
4. `bp_dashboard.html` 当前基于静态数据 (merchant_list_data.json)，非实时 BI 数据
