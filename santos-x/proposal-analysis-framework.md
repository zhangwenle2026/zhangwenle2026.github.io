# 📋 Santos X 客户报价方案分析框架

> 适用于Santos破独项目中High客户的Keeta签约报价方案拆解与评估
> 创建时间: 2026-07-17
> 来源案例: Caseirinha da Mãe (R$165K IQE, 212单/天)

---

## 一、基础信息提取

首先从提案/PPT中提取以下核心字段：

| 维度 | 需提取内容 |
|---|---|
| **客户名称** | 商户全名、品类、位置 |
| **日均订单** | iFood平台日均单量 |
| **IQE金额** | 签约投资金额（R$） |
| **佣金结构** | 免佣期 + 正式佣金率（含POL） |
| **回款周期** | D+N，是否有手续费 |
| **月费** | 是否免除、免除到何时 |
| **独家要求** | 是否要求独家 |
| **合同期限** | 年限（1Y/2Y/3Y/4Y） |
| **附加条款** | 法律支持、专属配送、营销资源等 |

---

## 二、财务测算（核心）

### 2.1 客户月GMV估算

```
月GMV = 日均订单 × 平均客单价 × 30天
```

**客单价参考（巴西市场）：**
| 品类 | 客单价范围 (R$) |
|---|---|
| Marmita/便当 | 15-30 |
| Pizza | 35-55 |
| Japanese/Poke | 40-60 |
| Burger | 25-40 |
| Dessert | 20-35 |
| Brazilian（正餐） | 30-50 |
| Açaí | 20-35 |

> ⚠️ 以上为估算参考，最好从BD获取实际客单价

### 2.2 Keeta月佣金收入

```
月佣金收入 = 月GMV × (佣金率 + POL率)
```

注意免佣期内佣金收入 = 0

### 2.3 IQE回收期

```
IQE回收期 = IQE金额 ÷ 月佣金收入 + 免佣月数
```

**判断标准：**
| 回收期 | 评价 |
|---|---|
| ≤ 6个月 | ✅ 优秀，果断推 |
| 7-12个月 | 🟡 合理，看合同期限 |
| 13-18个月 | ⚠️ 偏长，需要更强的战略理由 |
| > 18个月 | 🔴 风险高，建议调整IQE或争取独家 |

### 2.4 合同期ROI

```
合同总佣金 = 月佣金收入 × (合同月数 - 免佣月数)
合同ROI = (合同总佣金 - IQE) ÷ IQE × 100%
```

**判断标准：**
| ROI | 评价 |
|---|---|
| > 200% | ✅ 高回报 |
| 100-200% | 🟡 合理 |
| 50-100% | ⚠️ 一般，需其他战略价值支撑 |
| < 50% | 🔴 需重新评估 |

---

## 三、竞争力评估

### 3.1 佣金对比

```
商户月省佣金 = 月GMV × (竞对佣金率 - Keeta佣金率)
年省佣金 = 月省佣金 × 12
```

这是说服KP的最核心数字——"来Keeta你一年省多少钱"。

**竞对佣金参考：**
| 平台 | 佣金率 |
|---|---|
| iFood | 23-27%（普通）/ 12%（基础Plan） |
| 99 Food | 20-25% |
| Keeta（标准） | 9.9% + POL 3.2% = 13.1% |

### 3.2 回款对比

| 平台 | 回款 |
|---|---|
| iFood | D+30（标准） |
| 99 | D+14~D+30 |
| Keeta | D+7 无手续费 |

**现金流改善 = 月GMV × (竞对回款天数 - 7) ÷ 365 × 年化资金成本**

### 3.3 竞对报价对标

```
竞对签约金 vs Keeta IQE → 差额是多少？
竞对是否要求独家？→ 独家溢价如何？
```

> 🔴 如果竞对报价未知（competitor_price为空），必须要求BD先摸清再评估

---

## 四、风险评估矩阵

逐项检查以下风险因子：

| # | 风险因子 | 检查项 | 严重度 |
|---|---|---|---|
| 1 | **竞对信息空白** | competitor_price是否已知？99/iFood是否已接触？ | 🔴 高 |
| 2 | **KP关系不明** | kp_relationship字段是否填写？Hot/Neutral/Cold？ | 🔴 高 |
| 3 | **签约意愿不明** | sign_willingness是否填写？ | 🔴 高 |
| 4 | **BD交接** | 是否有BD交接？新BD是否已建立KP关系？ | 🟡 中 |
| 5 | **品类客单价风险** | 低客单价品类（marmita等）IQE回收期是否过长？ | 🟡 中 |
| 6 | **区域运营覆盖** | 商户所在区域是否有运营团队覆盖？ | 🟡 中 |
| 7 | **独家锁定** | iFood/99独家合同是否在有效期内？违约金多少？ | 🟡 中 |
| 8 | **提案时效性** | 提案制定距今多久？是否需要刷新？ | 🟢 低 |

**风险评级：**
- 🔴 高风险 ≥ 2项 → 暂缓推进，先补信息
- 🟡 中风险为主 → 可推进但需注意
- 🟢 低风险 → 正常推进

## 五、结论模板

最终输出结构：

```
### [客户名] 报价方案评估

**报价摘要：** IQE R$XX / 佣金X% / 合同XY
**财务测算：** 月GMV R$XX → 月佣金 R$XX → 回收期X个月 → 合同ROI X%
**竞争优势：** 商户年省佣金 R$XX / 回款提速X天
**风险等级：** 🟡/🔴/🟢 （列出主要风险项）
**建议：** 
- 推进 / 调整IQE / 先补信息再评估
- 具体行动项1
- 具体行动项2
```

---

## 六、使用说明

1. 拿到客户报价PPT/方案后，**先提取第一部分的基础信息**
2. 用第二部分的公式做财务测算（客单价如果不确定用品类参考值）
3. 第三部分做竞争力对标（需要competitor_price数据）
4. 第四部分过一遍风险矩阵
5. 用第五部分的模板输出结论

> 💡 如果数据库里该客户的关键字段为空（KP关系、签约意愿、竞对价格），
> 在分析中**必须标红指出**，并要求BD在X天内补齐后再做完整评估。
